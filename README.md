Service RU — Russian Language Patch

A Russian-language patch build of the Service app for BMW iDrive 7 (MGU), based on cauliflowermossgrape/idrive7-apps⁠￼.

This is simply a repackaged version with Russian interface text and Cyrillic font support, using the original project’s Russian localization. The app’s service functionality is unchanged.

Packaged for installation through MGU Store as a separate app named Service RU.

All credit for the original app and its Russian translation goes to the upstream authors and contributors.
